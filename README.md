# СОЗВОН

Нативное macOS-приложение для записи и живой транскрибации звонка или речи с микрофона.

## Требования

- macOS 13 или новее
- Xcode Command Line Tools (полный Xcode не нужен)
- для уточнения через Whisper — дополнительно `git` и `cmake`

## Сборка

```bash
./Scripts/build_app.sh
```

После сборки приложение будет здесь:

```text
dist/СОЗВОН.app
```

## Запуск

Откройте `dist/СОЗВОН.app`. При первом запуске macOS попросит доступ к микрофону, распознаванию речи и, для режима `Звонок`, к записи экрана/системного звука.

### Режимы записи

- `Оба` — одновременно системный звук (ScreenCaptureKit) и микрофон (AVAudioEngine), в **два отдельных файла и две отдельные распознавалки**. Даёт разметку по спикерам без диаризации: системный звук это `Собеседник`, микрофон это `Я`.
- `Звонок` — только системный звук.
- `Микрофон` — только микрофон.

В режиме `Оба` расшифровка выглядит так:

```text
[00:12] Я: а что там по срокам
[00:15] Собеседник: думаю к пятнице закроем
```

Если один канал отвалился, второй продолжает писать — сеанс закрывается только когда остановились оба.

### Словарь

Поле `Словарь` — имена, термины и названия проектов через запятую. Уходит в `contextualStrings` распознавалки (для новых сеансов) и в `--prompt` Whisper. Именно на этих словах распознавание спотыкается чаще всего.

Каждое нажатие `Слушать` создает новый сеанс: аудиофайл `.caf`, live-транскрипцию и запись в списке сеансов. Название выбранного сеанса можно редактировать в верхней части окна.

Для выбранного сеанса в окне есть встроенный аудиоплеер с паузой и перемоткой.

## Уточнение через Whisper

Live-распознавание идёт через Apple Speech — быстро, но средне по качеству. Готовую запись можно перераспознать локально через whisper.cpp, у которого заметно лучше русский и пунктуация.

Настройка (один раз):

```bash
./Scripts/setup_whisper.sh
```

Скрипт клонирует и собирает whisper.cpp (статически, с Metal), качает модель `large-v3-turbo-q5_0` и VAD-модель Silero. Всё кладётся **вне репозитория**, в `~/Library/Application Support/SOZVON/whisper/`. Нужны `git` и `cmake`.

Другая модель:

```bash
WHISPER_MODEL=medium ./Scripts/setup_whisper.sh
```

После настройки в окне появляется кнопка `Уточнить Whisper`. Она перегоняет `.caf` каждого канала в 16 кГц моно, гоняет через whisper-cli и собирает расшифровку обратно с метками спикеров. Live-версия при этом сохраняется — переключатель `Live / Whisper` рядом с кнопкой.

Аудио пишется в исходном качестве (48 кГц стерео для системного звука), а не в том 16 кГц моно, что слушает Apple Speech, — поэтому Whisper работает с полноценной записью.

## Хранение данных

```text
~/Library/Application Support/SOZVON/
  Recordings/
    <uuid>.caf          # системный звук (или микрофон в режиме «Микрофон»)
    <uuid>-mic.caf      # микрофон в режиме «Оба»
  whisper/              # бинарник и модели, создаётся setup_whisper.sh
  sessions.json
```

Live-транскрипты для Codex, Claude Code и других локальных агентов пишутся в:

```text
LiveTranscripts/
  current-transcript.txt
  current-session.json
  sessions/
    <session-folder>/
      transcript.txt
      session.json
```

`current-transcript.txt` обновляется во время активного сеанса. У каждого сеанса также есть отдельный `transcript.txt`; путь к нему показывается в окне приложения и копируется отдельной кнопкой.
